04 / Demo Script

5–10 minute walkthrough outline

Use this as the shot list for the demo video deliverable.

  1. Show the broken lab — pick one live case in Packet Tracer (e.g. C022 guest isolation) and demonstrate the symptom.
  2. Open the case in NetSage AI — walk through the symptom, topology note, and show-command evidence in the Case Explorer.
  3. Run AI diagnosis — click "Run AI Diagnosis" and read the JSON output: root cause, confidence, evidence, next command, fix steps.
  4. Run the rule checker — show the deterministic findings panel and explain how it complements the AI (or catches what it misses).
  5. Human review — mark Accept / Edit / Reject, add a reviewer note, and show the Responsible AI Log update live.
  6. Apply the fix & verify — apply the corrected fix in Packet Tracer and re-run the show command to prove the symptom is gone.
  7. Close on the dashboard — show issue-type coverage and the AI–human agreement rate across all 32 cases.
